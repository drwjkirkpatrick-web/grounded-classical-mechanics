# Flagship Project Threads

Some concepts are too big for one 45-minute lesson. These multi-day project threads run
through the course; each lesson in a thread is a complete lesson (pre/post tests,
advanced questions) that also advances one shared build. Project tags appear in
[CURRICULUM_MAP.md](../CURRICULUM_MAP.md).

## The Flagships

### 1. The School Windmill Water Pump — `windmill` (Unit 14, 8 lessons)
Rotor → tower → drivetrain → the Unit 8 diaphragm pump → measured water lifted per
minute → iteration → data → engineering report. The centrepiece of the year: a real
machine that moves real water, in the tradition of Kenya's Kijito wind pumps.
**Physics:** energy chains, torque, crank mechanisms, fluid pressure, efficiency, honest
measurement (wind speed vs output with error bars).

### 2. The Siphon Garden — `siphon-garden` (Unit 8, 3 lessons)
An overhead jerrican header tank, tubing over the bund, and measured flow into furrows.
Students design, install, troubleshoot (air leaks! priming!) and hand over a maintenance
document to next year's class. **Physics:** P = ρgh, atmospheric pressure, continuity,
flow measurement.

### 3. The Water Rocket — `water-rocket` (Unit 4, 3 lessons)
Bottle, water, bicycle pump, fins and a nose cone. Design → build → launch day with
range-vs-fill-fraction data. **Physics:** projectiles, action–reaction, momentum,
pressure; links forward to Unit 12's momentum treatment.

### 4. The Bridge — `bridge` (Unit 13, 3 lessons)
50 cm span, 1 kg midspan load, sticks and string only. Design → build → destructive
test with strength-to-weight scoring. **Physics:** tension/compression, triangulation,
moments, failure analysis.

### 5. The Pendulum Clock — `pendulum-clock` (Unit 11, 2 lessons)
Tune a pendulum to T = 1.000 s and keep time against a watch. **Physics:** T = 2π√(L/g),
calibration, drift and error budgets.

### 6. The Beam Balance — `beam-balance` (Unit 6, 2 lessons)
A steelyard-style weighing beam calibrated with water (100 mL = 100 g), then certified
against known masses. **Physics:** moments, calibration, systematic error.

### 7. The Class Orchestra — `orchestra` (Unit 15, threads: bottle-xylophone, one-string, pan-pipes, string-phone)
Bottle xylophones, one-string guitars, pan pipes and drums, assembled for a performance
with program notes that explain the physics. **Physics:** f ∝ 1/L, resonance, tension
and pitch, musical ratios (octave = ½ length).

### 8. The Capstone — `capstone` (Unit 16, 5 lessons + Science Day)
Teams choose and extend any thread (or propose a new one: the ram pump, a hydraulic
lift, a shake table) with a brief, prototype, data, iteration and a public demo at
Community Science Day.
