# Lesson 129: Levers Class 3: The Mwiko and the Human Arm

**Unit:** 6 — Simple Machines | **Duration:** 45 minutes | **Ages:** 10–17 (differentiated)
**CBE Alignment:** JS-FE;UP-FE | **Hands-On:** No | **Project:** —

## Learning Outcomes
By the end of the lesson, learners can:
1. Identify class 3 levers as levers where effort is between fulcrum and load.
2. Explain that class 3 levers multiply distance, not force.
3. Give examples of class 3 levers from Kenyan daily life.

## Materials
- Mwiko (wooden spoon) or similar tool
- Tweezers
- Fishing rod or long stick
- Notebook for each learner

## Vocabulary
- **Class 3 lever** *(ubao wa darasa 3)* — a lever with effort between fulcrum and load.
- **Tweezers** *(mende)* — a tool that uses class 3 lever action to grip small objects.
- **Fishing rod** *(fimbo ya uvuvi)* — a long lever that multiplies distance for casting.
- **Broom** *(broomu)* — a class 3 lever for sweeping.

## Pre-Test
1. Where is the effort in a class 3 lever?
2. Does a class 3 lever multiply force or distance?
3. Name two class 3 levers.

**Answer Key (Pre-Test):**
1. Between fulcrum and load.
2. Distance.
3. Tweezers, fishing rod, broom, human arm, tongs.

## Lesson Flow (45 Minutes)

1. **(5 min)** Settle and administer the Pre-Test. Collect Q3 by show of hands.

2. **(5 min)** Engage: Hold up a mwiko. "You hold the handle (fulcrum) and stir (effort) to move the food (load). Where is the effort?"

3. **(15 min)** Explore:
   - **Activity:** In groups of 4, learners identify class 3 levers.
   - **Human arm:** Elbow = fulcrum. Bicep = effort (between elbow and hand). Hand/load = at the end.
   - **Tweezers:** Finger pivot = fulcrum. Finger pressure = effort. Object gripped = load.
   - **Fishing rod:** Hand at butt = fulcrum. Hand on reel = effort. Tip = load.
   - **Key discovery:** Class 3 levers have effort between fulcrum and load. MA < 1 always. They multiply distance.

4. **(8 min)** Explain:
   - **Class 3 lever:** Effort between fulcrum and load. Load arm > effort arm always.
   - **MA < 1 always:** The output force is less than input force.
   - **Why use them:** They multiply distance and speed.
     - Tweezers: Small finger movement → large tip movement.
     - Fishing rod: Small hand movement → large tip movement.
     - Human arm: Small muscle contraction → large hand movement.
   - **Examples:**
     - Broom: Long handle multiplies sweep distance.
     - Tongs: Grip small objects precisely.
     - Mwiko: Stir food with wrist movement.
   - Kenyan context: Fishing rods for casting nets. Brooms for sweeping compounds. Mwikos for stirring ugali.

5. **(10 min)** Post-Test (see below). Learners work individually, then mark in pairs.

6. **(2 min)** Wrap: One learner identifies a class 3 lever and explains its advantage. Homework: find two class 3 levers at home.

## Post-Test
1. *(Mirrors Pre-Test Q1)* Where is the effort in a class 3 lever?
2. *(Mirrors Pre-Test Q2)* Does a class 3 lever multiply force or distance?
3. A tweezers has effort arm 2 cm and load arm 8 cm. Calculate MA.
4. Why is the human arm a class 3 lever despite MA < 1?

**Answer Key (Post-Test):**
1. **Between fulcrum and load**.
2. **Distance**.
3. MA = 2 / 8 = **0.25**.
4. It multiplies **distance** — small muscle contraction moves the hand over a large range.

## Advanced Questions (Ages 14–17)

**Q:** A fishing rod is 2 m long. The angler's hand is at the butt (fulcrum) and the reel hand is 0.4 m from the butt. Calculate (a) MA, (b) the force at the tip if the reel hand exerts 50 N, and (c) the distance the tip moves if the reel hand moves 0.1 m.

**Worked Answer:**
(a) Effort arm = 0.4 m. Load arm = 2 m.
    MA = 0.4 / 2 = **0.2**.

(b) Force at tip = MA × Effort = 0.2 × 50 = **10 N**.
    (The rod only exerts 10 N at the tip despite 50 N effort.)

(c) VR = 1/MA = 5.
    d_tip = VR × d_effort = 5 × 0.1 = **0.5 m**.

The tip moves 5× farther than the hand — this is why class 3 levers are used for casting.

**Q:** Compare all three lever classes. Create a table showing: fulcrum position, MA possibilities, and one example of each.

**Worked Answer:**
| Class | Fulcrum Position | MA | Example |
|-------|-----------------|----|---------|
| 1 | Between effort and load | Can be >1, =1, or <1 | Seesaw, crowbar, scissors |
| 2 | At one end | Always >1 | Wheelbarrow, bottle opener, nutcracker |
| 3 | At one end | Always <1 | Tweezers, fishing rod, human arm, broom |

**When to use each:**
- Class 1: When you need flexibility (variable MA).
- Class 2: When you need to multiply force (always MA > 1).
- Class 3: When you need to multiply distance/speed (always MA < 1).
