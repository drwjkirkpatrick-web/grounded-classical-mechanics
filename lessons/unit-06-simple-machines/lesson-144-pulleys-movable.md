# Lesson 144: Pulleys II: The Movable Pulley Halves the Effort

**Unit:** 6 — Simple Machines | **Duration:** 45 minutes | **Ages:** 10–17 (differentiated)
**CBE Alignment:** JS-FE;UP-FE | **Hands-On:** Yes | **Project:** —

## Learning Outcomes
By the end of the lesson, learners can:
1. Describe a movable pulley as one that moves with the load.
2. Explain why a movable pulley halves the effort force.
3. Calculate MA for single movable and combined pulley systems.

## Materials
- Two pulleys or homemade alternatives
- String or rope
- Load
- Support
- Notebook for each learner

## Vocabulary
- **Movable pulley** *(kifaa cha kutoa kilichosogea)* — a pulley attached to the load that moves with it.
- **Block and tackle** *(sisteme ya makifaa)* — a system of fixed and movable pulleys.
- **Tension** *(uvutano)* — the force in a rope.
- **Support rope** *(kamba ya kushikilia)* — the rope that holds a pulley system.

## Pre-Test
1. What is a movable pulley?
2. Does a movable pulley change direction?
3. If one rope supports a load, what is the tension?

**Answer Key (Pre-Test):**
1. A pulley that moves with the load.
2. No — it halves the force but same direction.
3. Equal to the load.

## Lesson Flow (45 Minutes)

1. **(5 min)** Settle and administer the Pre-Test. Collect Q2 by show of hands.

2. **(5 min)** Engage: Show a movable pulley setup. "Pull up, the load goes up. But the force is half. How?"

3. **(15 min)** Explore:
   - **Activity:** In groups of 4, learners test movable pulleys.
   - Set up a single movable pulley.
   - Attach load to pulley. Thread rope over fixed point, back under movable pulley.
   - Pull up to lift load.
   - Measure effort with spring balance.
   - **Key discovery:** Effort ≈ half the load. The rope shares the load between two strands.

4. **(8 min)** Explain:
   - **Why effort is halved:**
     - Two rope strands support the load.
     - Each strand carries half the load.
     - The effort pulls one strand → effort = half load.
   - **MA = 2:**
     - Ideal: effort = load / 2.
     - Real: slightly more due to friction and rope weight.
   - **Combined systems:**
     - Fixed + movable: changes direction AND halves force.
     - Multiple pulleys: more strands = more MA.
     - Block and tackle: MA = number of supporting strands.
   - **Trade-off:**
     - More MA → more rope to pull.
     - MA = 2 → pull 2 m to lift 1 m.
   - Kenyan context: Construction sites use block and tackle for lifting materials. Sailors use pulley systems for sails.

5. **(10 min)** Post-Test (see below). Learners work individually, then mark in pairs.

6. **(2 min)** Wrap: One learner explains why two strands halve the force. Homework: draw a 3-pulley system and calculate MA.

## Hands-On Build: Movable Pulley System

### Parts
- Two pulleys — 2 — classroom/home
- String — 2 m — classroom
- Load — 1 — classroom
- Support — 1 — classroom
- Spring balance — 1 — classroom

### Workflow
1. Attach fixed pulley to support.
2. Thread rope through fixed pulley, down through movable pulley.
3. Attach load to movable pulley.
4. Secure free end of rope to support.
5. Pull movable pulley up to lift load.
6. Measure effort with spring balance.
7. Compare effort to load weight.
8. **Checkpoint:** Count the strands supporting the load. The number of strands equals the ideal MA.

### Common Mistakes
- **Wrong threading:** Not creating two supporting strands. Fix: trace rope path carefully.
- **Measuring friction:** Pulley friction increases effort. Fix: oil pulleys or subtract friction.
- **Pulling at angle:** Angled pull increases effort. Fix: pull vertically.

## Post-Test
1. *(Mirrors Pre-Test Q1)* What is a movable pulley?
2. *(Mirrors Pre-Test Q2)* Does a movable pulley change direction?
3. A 60 N load is lifted with a single movable pulley. What is the ideal effort?
4. If MA = 2, how far must you pull to lift the load 1 m?

**Answer Key (Post-Test):**
1. A pulley that **moves with the load**.
2. **No** — it halves force but keeps direction.
3. Effort = 60 / 2 = **30 N**.
4. **2 m** (MA = distance ratio too).

## Advanced Questions (Ages 14–17)

**Q:** A block and tackle has 4 supporting strands. Calculate (a) ideal MA, (b) effort to lift 200 kg, (c) distance pulled to raise load 5 m, and (d) efficiency if actual effort is 600 N.

**Worked Answer:**
(a) Ideal MA = **4**.

(b) Load = 200 × 10 = 2000 N.
    Ideal effort = 2000 / 4 = **500 N**.

(c) Distance pulled = 4 × 5 = **20 m**.

(d) Actual effort = 600 N.
    Efficiency = (ideal effort / actual effort) × 100% = (500/600) × 100% = **83.3%**.

Or: η = (load × height) / (effort × distance) = (2000 × 5) / (600 × 20) = 10,000/12,000 = **83.3%**.

**Q:** Draw a system with one fixed and one movable pulley that both changes direction and halves the force. Trace the rope and identify the number of supporting strands.

**Worked Answer:**
**Setup:**
1. Fixed pulley at top support.
2. Rope goes down from fixed pulley to movable pulley (attached to load).
3. Rope goes up from movable pulley and is secured to top support.
4. Pull free end of rope down.

**Tracing:**
- Pull down on free end (direction changed by fixed pulley).
- Rope goes up through movable pulley, lifting load.
- Two strands support load: one from fixed pulley, one to support.

**Supporting strands:** **2**.
**MA = 2**.

This system combines the advantages of both fixed (direction change) and movable (force multiplication) pulleys.
