# Lesson 146: Pulley Lab: Effort vs Strand Count

**Unit:** 6 — Simple Machines | **Duration:** 45 minutes | **Ages:** 10–17 (differentiated)
**CBE Alignment:** JS-FE;UP-FE | **Hands-On:** Yes | **Project:** —

## Learning Outcomes
By the end of the lesson, learners can:
1. Measure effort force for pulley systems with different numbers of strands.
2. Plot a graph of effort vs number of strands.
3. Verify that MA increases with strand count.

## Materials
- Multiple pulleys
- String
- Load
- Spring balance
- Support
- Graph paper
- Notebook for each learner

## Vocabulary
- **Strand count** *(idadi ya nyuzi)* — the number of rope strands supporting the load.
- **Effort force** *(nguvu ya juhudi)* — the force applied to lift a load.
- **Graph** *(mchoro)* — a visual representation of data.
- **Trend** *(mwelekeo)* — the general direction of data points.

## Pre-Test
1. What happens to effort as strand count increases?
2. Does more strands mean less distance to pull?
3. How would you test this?

**Answer Key (Pre-Test):**
1. Effort decreases.
2. No — more strands means more distance to pull.
3. Build systems with 1, 2, 3, 4 strands and measure effort.

## Lesson Flow (45 Minutes)

1. **(5 min)** Settle and administer the Pre-Test. Collect by show of hands.

2. **(5 min)** Engage: "Can we predict effort from strand count? Let's find out."

3. **(15 min)** Explore:
   - **Activity:** In groups of 4, learners build four pulley systems.
   - System 1: Fixed pulley (1 strand).
   - System 2: Movable pulley (2 strands).
   - System 3: Block and tackle (3 strands).
   - System 4: Block and tackle (4 strands).
   - Measure effort for each with same load.
   - Record in table.
   - **Key discovery:** Effort halves when strands double. MA = strand count.

4. **(8 min)** Explain:
   - **Data analysis:**
     - Plot effort (y-axis) vs strand count (x-axis).
     - The graph should show a decreasing trend.
     - Inverse relationship: effort ∝ 1/strands.
   - **Verification:**
     - Ideal MA = strand count.
     - Actual MA = load / measured effort.
     - Compare to strand count.
   - **Sources of error:**
     - Friction in pulleys.
     - Rope weight.
     - Measurement inaccuracy.
   - **Conclusion:** More strands = less effort but more distance.

5. **(10 min)** Post-Test (see below). Learners work individually, then mark in pairs.

6. **(2 min)** Wrap: Groups share graphs. Homework: predict effort for 6 strands.

## Hands-On Build: Effort vs Strand Count Lab

### Parts
- Pulleys — 6 — hardware
- String — 4 m — classroom
- Load (constant) — 1 — classroom
- Spring balance — 1 — classroom
- Support — 1 — classroom
- Graph paper — 1 per group — classroom

### Workflow
1. Build fixed pulley (1 strand). Measure effort.
2. Build movable pulley (2 strands). Measure effort.
3. Build block and tackle with 3 strands. Measure effort.
4. Build block and tackle with 4 strands. Measure effort.
5. Record all data in a table.
6. Plot effort vs strand count.
7. Calculate actual MA for each.
8. **Checkpoint:** Use the same load for all trials. Changing the load invalidates comparison.

### Common Mistakes
- **Different loads:** Invalid comparison. Fix: use same load.
- **Not counting strands:** Wrong MA prediction. Fix: trace rope carefully.
- **Accelerating:** Force changes. Fix: pull slowly and steadily.

## Post-Test
1. *(Mirrors Pre-Test Q1)* What happens to effort as strand count increases?
2. *(Mirrors Pre-Test Q2)* Does more strands mean less distance?
3. A 100 N load is lifted with 4 strands. What is ideal effort?
4. Why is actual effort greater than ideal?

**Answer Key (Post-Test):**
1. **Decreases**.
2. **No** — more strands means **more distance**.
3. 100 / 4 = **25 N**.
4. **Friction** and rope weight.

## Advanced Questions (Ages 14–17)

**Q:** Plot ideal effort vs strand count for a 200 N load with 1, 2, 3, 4, 5, 6 strands. Describe the shape of the graph. Calculate the percentage error if actual effort for 4 strands is 58 N.

**Worked Answer:**
**Ideal effort:**
- 1 strand: 200 N
- 2 strands: 100 N
- 3 strands: 66.7 N
- 4 strands: 50 N
- 5 strands: 40 N
- 6 strands: 33.3 N

**Graph shape:**
A decreasing curve (hyperbola). As strand count increases, effort decreases but never reaches zero.

**Percentage error:**
Actual = 58 N. Ideal = 50 N.
Error = ((58 − 50) / 50) × 100% = **16%**.

**Q:** A workshop needs to lift a 500 kg engine. The strongest worker can exert 400 N. Design a pulley system that allows this worker to lift the engine, and calculate the minimum number of strands needed.

**Worked Answer:**
Load = 500 × 10 = 5000 N.

Ideal strands needed: 5000 / 400 = **12.5**.

Since we can't have half strands, minimum = **13 strands**.

But friction reduces efficiency. With 80% efficiency:
Actual effort = ideal effort / 0.80.

So ideal effort must be ≤ 400 × 0.80 = 320 N.

Strands needed: 5000 / 320 = **15.6** → **16 strands**.

**Design:**
Two blocks with 8 pulleys each, or a compound system.
