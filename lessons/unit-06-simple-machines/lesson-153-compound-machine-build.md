# Lesson 153: Design Challenge II: Build and Demonstrate

**Unit:** 6 — Simple Machines | **Duration:** 45 minutes | **Ages:** 10–17 (differentiated)
**CBE Alignment:** JS-FE;UP-FE | **Hands-On:** Yes | **Project:** village-machine

## Learning Outcomes
By the end of the lesson, learners can:
1. Build a prototype from their design plan.
2. Test the machine and record results.
3. Demonstrate the machine to the class and explain its physics.

## Materials
- Materials gathered from Lesson 152
- Tools (knife, string, tape)
- Load for testing
- Notebook for each learner

## Vocabulary
- **Prototype** *(mfano wa kwanza)* — a first working model.
- **Test** *(kupima)* — trying the machine to see if it works.
- **Demonstration** *(onyesho)* — showing how the machine works.
- **Iterate** *(kurekebisha)* — making improvements based on testing.

## Pre-Test
1. What is a prototype?
2. Why test before demonstrating?
3. What will you do if your machine doesn't work?

**Answer Key (Pre-Test):**
1. A first working model.
2. To fix problems before the public demonstration.
3. Troubleshoot, adjust, iterate.

## Lesson Flow (45 Minutes)

1. **(5 min)** Settle and administer the Pre-Test. Groups review designs from Lesson 152.

2. **(5 min)** Engage: "Today we build. Your design becomes real."

3. **(15 min)** Explore:
   - **Activity:** In groups of 4, learners build their machines.
   - Follow design plans from Lesson 152.
   - Build quickly but carefully.
   - Test as you build.
   - **Key discovery:** Building reveals problems that designing doesn't.

4. **(8 min)** Explain:
   - **Building tips:**
     - Start with the frame.
     - Add moving parts.
     - Test each component.
     - Adjust before final assembly.
   - **Testing:**
     - Does it solve the problem?
     - Is the MA as expected?
     - Is it safe?
     - Record all observations.
   - **Iteration:**
     - Most first designs fail.
     - Failure teaches more than success.
     - Adjust and try again.

5. **(10 min)** Post-Test (see below). Learners work individually, then mark in pairs.

6. **(2 min)** Wrap: Groups prepare for demonstration. Homework: prepare a 2-minute explanation.

## Hands-On Build: Village Machine Prototype

### Parts
- Materials from Lesson 152 — various — gathered
- Tools — basic — classroom
- Load — 1 — classroom

### Workflow
1. Build frame.
2. Add simple machines.
3. Test movement.
4. Apply load.
5. Measure effort and output.
6. Compare to calculated MA.
7. **Checkpoint:** Before full testing, verify the machine is stable. A collapsing machine is dangerous.

### Common Mistakes
- **Building too big:** Overambitious designs fail. Fix: build a small-scale model first.
- **Weak joints:** Falling apart under load. Fix: tie securely, use multiple attachment points.
- **Not testing components:** Everything works until assembled. Fix: test each part separately.

## Advanced Questions (Ages 14–17)

**Q:** Your machine achieved 60% of its expected MA. List three possible causes and how to test each one.

**Worked Answer:**
**Cause 1: Friction**
- Test: Disassemble joints, observe wear marks.
- Fix: Add lubricant or reduce contact area.

**Cause 2: Flexing materials**
- Test: Apply load and observe bending.
- Fix: Use stiffer materials or add supports.

**Cause 3: Wrong dimensions**
- Test: Measure actual vs planned dimensions.
- Fix: Rebuild to specifications.

**Cause 4: Rope stretch**
- Test: Measure rope length under load.
- Fix: Use non-stretchy material.

**Q:** Calculate the efficiency of your machine using measured input and output work. Suggest one modification to improve it.

**Worked Answer:**
Open-ended. Example:

Input work = effort force × effort distance.
Output work = load force × load distance.

Efficiency = (output / input) × 100%.

If efficiency is 50%:
- Modification: Oil moving parts → reduce friction → higher efficiency.
