# Lesson 226: What Keeps It Circling? The Inward Pull

**Unit:** 10 — Circular & Rotational Motion | **Duration:** 45 minutes | **Ages:** 10–17 (differentiated)
**CBE Alignment:** G10-PHY-1.5;JS-FE | **Hands-On:** Yes | **Project:** —

## Learning Outcomes
By the end of the lesson, learners can:
1. Demonstrate that circular motion requires an inward force.
2. Feel centripetal force with simple equipment.
3. Explain that removing the inward force makes the object fly off tangent.

## Materials
- String — 1 m per group
- Small weight (stone, washer) — 1 per group
- Notebook for each learner

## Vocabulary
- **Centripetal force** *(nguvu ya kuelekea katikati)* — the inward force that keeps an object moving in a circle.
- **Inward pull** *(kuvuta kwa ndani)* — the force directed toward the centre of rotation.
- **Tangent** *(mstari wa kugusa)* — a line that touches the circle at one point, showing the direction the object would fly if released.
- **Circular path** *(njia ya duara)* — the curved trajectory maintained by centripetal force.

## Pre-Test
1. What happens if you let go of a spinning stone on a string?
2. Which direction does the string pull?
3. Can something move in a circle with no forces?

**Answer Key (Pre-Test):**
1. It flies off in a straight line (tangent).
2. Toward your hand (inward, toward centre).
3. No — circular motion always needs an inward force.

## Lesson Flow (45 Minutes)

1. **(5 min)** Settle and administer the Pre-Test. Collect Q1 by show of hands.

2. **(5 min)** Engage: "Spin a stone on a string. Let go. Where does it go?"

3. **(15 min)** Explore:
   - **Activity:** In groups of 4, learners feel centripetal force.
   - Tie weight to string.
   - Swing in horizontal circle.
   - Feel pull in hand.
   - Let go — stone flies off tangent.
   - Try different speeds — faster = stronger pull.
   - Try different radii — shorter string = stronger pull at same speed.
   - **Key discovery:** Faster spin and shorter string both increase the inward pull. The string provides the centripetal force.

4. **(8 min)** Explain:
   - **Centripetal force:**
     - "Centripetal" means "centre-seeking".
     - Always directed toward centre of circle.
     - Required to change direction continuously.
   - **What happens without it:**
     - Newton's first law: objects move straight unless forced.
     - Remove inward force → object flies tangent.
     - Not "flung outward" — just continues straight.
   - **Formula (introduced):**
     - F = mv²/r
     - More mass → more force needed.
     - Faster speed → much more force (v squared!).
     - Smaller radius → more force needed.
   - **Everyday examples:**
     - Spinning a bucket: arm provides inward force.
     - Satellite in orbit: gravity provides inward force.
     - Car turning: friction provides inward force.

5. **(10 min)** Post-Test (see below). Learners work individually, then mark in pairs.

6. **(2 min)** Wrap: One learner explains why the string must pull inward. Homework: find three examples of centripetal force.

## Hands-On Build: Feeling Centripetal Force

### Parts
- String — 1 m — home
- Small weight — 1 — stone/washer
- Space to swing — outdoors or large room

### Workflow
1. Tie weight securely to string.
2. Hold string, swing weight in horizontal circle.
3. Feel pull in hand.
4. Swing faster. Feel stronger pull.
5. Shorten string. Feel stronger pull.
6. Let go. Observe tangent flight.
7. **Checkpoint:** For horizontal circle, hand must be above the weight (conical pendulum). True horizontal requires supporting the weight against gravity.

### Common Mistakes
- **Not secure knot:** Weight flies off. Fix: double-knot.
- **Hitting obstacles:** Clear space needed. Fix: swing outdoors.
- **Vertical circle:** Confuses with gravity. Fix: keep horizontal for pure centripetal feel.

## Post-Test
1. *(Mirrors Pre-Test Q1)* What happens when you let go?
2. *(Mirrors Pre-Test Q2)* Which direction does string pull?
3. What happens to the pull if you spin faster?
4. Name one everyday source of centripetal force.

**Answer Key (Post-Test):**
1. Flies off in **straight line** (tangent).
2. **Inward** (toward centre).
3. **Pull gets stronger** (F ∝ v²).
4. Any: **string tension**, **gravity** (satellite), **friction** (car turning).

## Advanced Questions (Ages 14–17)

**Q:** A 0.2 kg stone is swung in a horizontal circle of radius 0.5 m at 3 m/s. Calculate (a) the centripetal force, and (b) the tension in the string. If the string breaks, what is the stone's path?

**Worked Answer:**
(a) F = mv²/r = 0.2 × 3² / 0.5 = 0.2 × 9 / 0.5 = **3.6 N**.

(b) Tension = centripetal force = **3.6 N** (in horizontal circle, assuming gravity is managed by slight upward angle).

**After string breaks:**
- Flies tangent to circle at break point.
- Path is straight line (Newton's first law).
- Not outward — just no longer turning.

**Q:** Explain the physics of a conical pendulum (string at angle to vertical) and derive the relationship between period, length, and angle.

**Worked Answer:**
**Conical pendulum:**
- Weight swings in horizontal circle.
- String traces a cone.
- Vertical: T cos θ = mg.
- Horizontal: T sin θ = mv²/r.

**From vertical:**
cos θ = g/(ω²L)
where ω = angular velocity, L = string length.

**Period:**
T = 2π√(L cos θ / g)

**Key insight:**
- Steeper angle (larger θ) → shorter period.
- Longer string → longer period.
- Independent of mass.

**Application:**
- Used in centrifugal governors.
- Demonstrates vector components.
